# Railway staging

Astro Window is a set of ordinary containers plus Postgres and Redis. Nothing in application code depends on Railway.

Project: **shimmering-quietude**. Desired state lives in [`.railway/railway.ts`](../.railway/railway.ts). After changing that file, run `railway config plan` and `railway config apply`.

| Railway service | Image / source | Notes |
| --- | --- | --- |
| `gateway` | `gateway/Dockerfile` | Public HTTPS. Proxies `/` to `frontend` and `/api` + `/health` to `backend`. |
| `frontend` | `frontend/Dockerfile` | Private. `VITE_API_BASE_URL=/api/v1`. Listens on `PORT`. |
| `backend` | `backend/Dockerfile` (repo root context) | Private. Health check `/health`. Start command runs `entrypoint.sh` (Alembic + catalogue seed, then uvicorn on `$PORT`). Image includes `data/catalogue`. |
| `worker` | same image | `celery … worker` — entrypoint skips migrate/seed. |
| `beat` | same image | `celery … beat` — entrypoint skips migrate/seed. |
| `Postgres` | Railway plugin | `DATABASE_URL` is rewritten to `postgresql+psycopg://` in app config. |
| `Redis` | Railway plugin | `REDIS_URL`, `CELERY_BROKER_URL`, `CELERY_RESULT_BACKEND`. |

Variables to add in the dashboard if you want magic-link sign-in: `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`. `SECRET_KEY` is generated by IaC.

The public Railway domain is attached to `gateway` so cookies stay first-party (`UI` on `/`, API on `/api`).
